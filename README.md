# nvim-config

NVIM CONFIG DEPENDENCIES:

Mason and Nvim-LSP:
- requires node.js to be installed
- requires zip

Telescope:
- requires ripgrep and fd, install both as actual files, not vim plugins

Treesitter:
- install tree-sitter-cli tool

Conform Formatter:
- clang-format
- ruff
- stylua
- rustfmt
- prettier
- prettierd
